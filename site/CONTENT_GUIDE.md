# Writing docs pages

Site: Astro + Starlight in `site/`. Pages live in `src/content/docs/<section>/<slug>.mdx`, URL `/<section>/<slug>/`.
Sections: start, concepts, guides, migration, reference. `api/` is generated by TypeDoc from `../src/index.ts`: never edit it.
Source of truth: `../src/*.ts` and `../test/*.spec.ts`. Never document something you didn't verify in the source.

## Facts that are easy to get wrong
- The default timeout is 30000 ms, not off. `0` disables it. The timeout only aborts the signal; it never ends the response.
- The middleware watches the *response*: `close` before `finish` = client disconnected. A finished response never aborts.
- The abort reason is an `AbortError` with `reason: 'timeout' | 'client-disconnected'`. `fetch` rejects with it as is;
  Node core APIs wrap it in their own AbortError (`error.cause`).
- Without `AbortExceptionFilter` an escaped AbortError is a 500. With it: timeout/unknown -> 408, disconnect or headers sent -> nothing.
- On Fastify, outside the decorator read `req.raw[ABORT_SIGNAL]`.
