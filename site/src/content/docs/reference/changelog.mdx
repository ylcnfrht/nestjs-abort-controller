## 1.3.1 (2026-10-17)

- README: author and support links.

## 1.3.0 (2026-10-17)

- **Fix:** requests with a body no longer abort as soon as the body is read ([#2](https://github.com/ylcnfrht/nestjs-abort-controller/pull/2)).
- **Fix:** module options no longer leak between `forRoot()` / `forRoutes()` calls; options come through DI.
- **New:** Fastify support.
- **New:** `AbortError.reason` and abort reasons on the signal.
- **New:** `AbortExceptionFilter`.
- **New:** `ABORT_SIGNAL` / `ABORT_CONTROLLER` symbol keys ([#1](https://github.com/ylcnfrht/nestjs-abort-controller/pull/1)).
- **Deprecated:** `req.abortSignal`, `req.abortController`, `AbortControllerMiddleware.setOptions()`.

See [1.2 → 1.3](/migration/1-2-to-1-3/).

## 1.2.0 (2025-08-11)

## 1.1.0 (2025-07-30)

- First public release: `AbortControllerModule` (`forRoot`, `forRoutes`), `@NestAbortSignal()`, `throwIfAborted`, `AbortError`, configurable timeout and logging.
