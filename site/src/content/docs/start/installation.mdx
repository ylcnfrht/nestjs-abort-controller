## Requirements

| | |
| --- | --- |
| NestJS | 11 (`@nestjs/common`, `@nestjs/core` are peer dependencies) |
| Adapter | `@nestjs/platform-express` or `@nestjs/platform-fastify` |
| Node.js | whatever your NestJS version needs (Nest 11: Node 20+) |
| Other peers | `reflect-metadata`, `rxjs` (already in every Nest app) |

There are no runtime dependencies. The package ships CommonJS with type definitions, which works from both
CommonJS and ESM Nest projects.
