No code changes are needed.

## Fixed

- Requests with a body (POST/PUT/PATCH) no longer abort the signal as soon as the body is read. The signal now aborts
  only when the client really disconnects or the timeout fires.
- Options passed to `forRoot()` / `forRoutes()` no longer leak between calls.

## New

- Fastify adapter support.
- `AbortError.reason` (`'timeout' | 'client-disconnected'`), and the signal's own `reason` is that `AbortError`.
- Optional [`AbortExceptionFilter`](/concepts/error-responses/).
- `ABORT_SIGNAL` / `ABORT_CONTROLLER` symbol keys for reading the signal [outside controllers](/concepts/outside-controllers/).

## Deprecated (still work, removed in 2.0)

| Old | Use instead |
| --- | --- |
| `req.abortSignal` | `@NestAbortSignal()` or `req[ABORT_SIGNAL]` |
| `req.abortController` | `req[ABORT_CONTROLLER]` |
| `AbortControllerMiddleware.setOptions()` | `forRoot()` / `forRoutes()`, or `new AbortControllerMiddleware(options)` |
